DEV LOG

技術の見どころ

リードプログラマー・チームリーダーとして、ゲームの中心になるプレイヤーシステムを担当しました。

TECH HIGHLIGHT 01
四肢を回してキャラクターを操作するプレイヤーシステム
  1. 課題

    実装初期は Transform の Rotation で四肢を回していましたが、地面を押す力が足りず、画面の動きが小さく、キャラクターの動きも激しくなりませんでした。

  2. 解決

    回転の仕組みを Rigidbody の AddForce で特定の方向に力を加える方式に変更。回した手足で壁や床を強く押せるようになり、画面とキャラクターの激しい動きを表現できました。

  3. 結果

    手足を回すたびにキャラクターが大きく暴れる、見ていても笑える格闘ゲームになりました。ゲームジャムでは多くの方に笑ってもらえ、その後、東京ゲームショウ2026にも出展しました。

DEV LOG

技術の見どころ

ジェネラリスト（総合管理）として、タイトルシーンの制作、各シーンの結合、3言語のローカライズを担当しました。

TECH HIGHLIGHT 01
パーツを分けて動かすタイトルシーン
  1. 課題

    タイトル画面を1枚絵で作ると、背景もキャラクターも一緒に固定され、画面に動きを付けることができませんでした。

  2. 解決

    背景の集中線とキャラクターを1枚絵から切り離し、それぞれ別のUIとして配置。パーツごとにアニメーションを付けられるようにしました。

  3. 結果

    背景とキャラクターが別々に動く、ゲームを始める前からゲームの勢いが伝わるタイトル画面になりました。

TECH HIGHLIGHT 02
自作フォントを使った3言語のローカライズ
  1. 課題

    国際チームのため日本語・英語・フランス語に対応したかったものの、既存のフォントでは言語によって対応していない文字がありました。

  2. 解決

    チームメンバーが自作したフォントを使い、3言語に対応するローカライズ処理を実装。翻訳で長くなる文章も、画面上で自然に見えるように調整しました。

  3. 結果

    ゲームの雰囲気に合ったフォントのまま、日本語・英語・フランス語の3言語で遊べるゲームになりました。
